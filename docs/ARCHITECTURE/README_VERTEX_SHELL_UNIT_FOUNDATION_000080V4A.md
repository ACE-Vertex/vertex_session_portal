# Vertex Shell Unit Foundation 000080V4A

Vertex Shell is not a separate product/project in this generation.

It is an internal unit of:

`G:\Vertex_Project\Development\vertex_session_portal`

## Intent

PowerShell remains the compatibility organ at first, while the Session Portal
owns the human command cockpit, streaming output, cwd, stop control and
evidence metadata.

The future predation path is:

PowerShell command
→ typed Vertex Shell command
→ native provider/capability
→ VXN operation
→ Evidence

## 000080V4A scope

ADD ONLY:
- shared Vertex Shell contracts
- main-process Vertex Shell service
- dedicated Vertex Shell IPC registration module
- renderer Vertex Shell Unit component + CSS
- READ-ONLY current-source wiring Ray

Existing Portal files are intentionally not modified in V4A. The Ray captures
their exact current hashes/anchors so V4B can wire the unit with a narrow patch.

No Vera/agent auto-command execution is exposed in V4A. The command cockpit is
for direct human interaction.
